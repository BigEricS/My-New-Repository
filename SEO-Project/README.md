# SEO Project — AI-Powered SEO Workflow

Built around the **AI SEO Playbook** from [aiwithkyle.com](https://aiwithkyle.com).

## Folder Structure

```
SEO-Project/
├── PDFs/
│   └── AI-SEO-Playbook/     ← Drop downloaded PDFs from aiwithkyle.com here
├── Research/
│   ├── keywords/            ← Keyword research files (CSV, XLSX, JSON)
│   ├── competitors/         ← Competitor analysis
│   └── backlinks/           ← Backlink opportunities
├── Content/
│   ├── briefs/              ← Content briefs generated by AI
│   ├── drafts/              ← Article drafts in progress
│   └── published/           ← Final published content records
├── Tools/                   ← Custom SEO scripts and automation
├── Prompts/                 ← Claude AI prompts for SEO tasks
└── Reports/
    ├── monthly/             ← Monthly performance reports
    └── audits/              ← Site audit reports
```

## Getting Started

### 1. Add Your PDFs
Download the PDFs from [aiwithkyle.com/join/thank-you](https://aiwithkyle.com/join/thank-you)
while logged in, then place them in `PDFs/AI-SEO-Playbook/`.

### 2. Keyword Research Workflow
1. Use `Prompts/keyword-research.md` prompts with Claude
2. Export results to `Research/keywords/`
3. Build content briefs in `Content/briefs/`

### 3. Content Creation Workflow
1. Keyword → Brief (`Content/briefs/`)
2. Brief → Draft (`Content/drafts/`)
3. Publish → Log in `Content/published/`

### 4. Reporting
- Run monthly checks and save to `Reports/monthly/`
- Full audits go in `Reports/audits/`
