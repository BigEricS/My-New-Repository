# Claude SEO Prompts — Keyword Research

## 1. Seed Keyword Expansion
```
You are an SEO expert. Given this seed keyword: [KEYWORD]
Generate 20 related long-tail keywords with:
- Search intent (informational / commercial / transactional / navigational)
- Estimated difficulty (low / medium / high)
- Suggested content format (blog post / landing page / comparison / listicle)
```

## 2. Keyword Clustering
```
Group these keywords into topical clusters for a content silo structure:
[PASTE KEYWORD LIST]

For each cluster:
- Name the pillar topic
- List supporting subtopics
- Suggest internal linking order
```

## 3. Competitor Gap Analysis
```
My website covers: [YOUR NICHE]
My top 3 competitors are: [COMPETITOR 1], [COMPETITOR 2], [COMPETITOR 3]

Identify keyword gaps I should target that they rank for but I don't.
Focus on keywords with buying intent first.
```

## 4. Search Intent Matching
```
For the keyword "[KEYWORD]", analyze:
1. What does the searcher want to accomplish?
2. What content format best satisfies this intent?
3. What should the page's H1, meta title, and meta description be?
4. What 5 questions should the content answer?
```
