# Claude SEO Prompts — Content Creation

## 1. Content Brief Generator
```
Create a detailed SEO content brief for the keyword: [TARGET KEYWORD]

Include:
- Target audience persona
- Search intent
- Recommended word count
- H1, H2, H3 structure outline
- Key points to cover per section
- Internal linking suggestions
- External authority sources to cite
- FAQs to include (for FAQ schema)
- Call to action
```

## 2. SEO Blog Post Draft
```
Write a [WORD COUNT]-word SEO-optimized blog post for the keyword "[TARGET KEYWORD]".

Requirements:
- Use the keyword naturally in H1, first 100 words, and conclusion
- Include 3-5 LSI/semantic keywords: [LSI KEYWORDS]
- Tone: [TONE — e.g. conversational, authoritative, friendly]
- Structure: intro → main sections → FAQ → conclusion + CTA
- Avoid keyword stuffing
```

## 3. Meta Title & Description
```
Write 5 variations of meta title and meta description for:
Keyword: [KEYWORD]
Page topic: [TOPIC]

Rules:
- Title: under 60 characters, include keyword near front
- Description: under 160 characters, include keyword, add a CTA
```

## 4. Content Refresh Prompt
```
Here is my existing article on "[TOPIC]": [PASTE ARTICLE]

It currently ranks for [KEYWORD] in position [POSITION].
Suggest specific improvements to:
1. Update outdated information
2. Add missing sections competitors cover
3. Improve readability and formatting
4. Strengthen the intro and conclusion
5. Add FAQ section with schema markup
```
