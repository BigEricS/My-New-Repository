# Replace Your SEO Agency With AI — Slide Deck Summary

## Core Argument
Traditional SEO agencies are overpriced, slow, and ignoring AI search.
Replace them with a Claude Code skill running 7 parallel agents in ~3 minutes for $20/month.

## The 7 Agents
1. **Technical SEO** — crawl errors, site speed, indexability, Core Web Vitals
2. **On-Page Analysis** — titles, meta descriptions, heading structure, keyword usage
3. **Content Quality (E-E-A-T)** — expertise, authoritativeness, trustworthiness signals
4. **Schema Markup** — structured data gaps and opportunities
5. **Image Optimization** — alt text, file size, format (WebP), lazy loading
6. **AI Search / GEO** — Generative Engine Optimization for ChatGPT, Claude, Perplexity
7. **Strategic Planning** — prioritized action plan with effort/impact scoring

All 7 agents triggered by a single URL input, run in parallel.
